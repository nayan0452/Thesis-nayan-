PRAC (Private Random Access Computations) is a secure multi-party computation system designed specifically for operations that require random access to memory. Here's a comprehensive explanation of what it is:
PRAC System Overview
PRAC implements three-party secure computation, focusing on computations that require random access to memory. The system consists of:
Three Parties:
Two computational peers (Parties 0 and 1)
One server (Party 2) that aids computation but does less work
Core Functionality:
Secure computation of operations on private data
Private memory access through Distributed Point Functions (DPFs)
Support for various data structures with oblivious access patterns
Key Features:
DuoRAM: A bandwidth-efficient distributed Oblivious RAM (ORAM) implementation
Secure Data Structures: Binary search trees, AVL trees, heaps, and tries
Resource Precomputation: Multiplication triples, AND triples, and DPFs can be precomputed
Security Properties:
Prevents leakage of access patterns
Ensures data privacy among the participating parties
Provides security against semi-honest adversaries
Technical Aspects
Memory Sharing Schemes:
Additive sharing (RegAS)
XOR sharing (RegXS)
Bit sharing (RegBS)
Operational Modes:
Preprocessing Mode: Precomputes resources for later use
Online Mode: Uses precomputed resources for actual computation
Online-Only Mode: Computes resources on-the-fly
Supported Operations:
Dependent/independent reads and writes
Binary search
Heap operations (insert, extract-min)
AVL tree operations
Stream sampling
Research Context
This system is the implementation of research work published in:
"PRAC: Round-Efficient 3-Party MPC for Dynamic Data Structures" (PoPETs 2024)
by Sajin Sasy, Adithya Vadapalli, and Ian Goldberg.
The key innovation of PRAC is its ability to efficiently handle dynamic data structures in a secure multi-party computation setting, which is particularly challenging because access patterns must be hidden from other parties.
Applications
PRAC can be used for:
Privacy-preserving database operations
Secure computation on sensitive data structures
Private information retrieval
Secure search and analytics on confidential data
The experiments you ran demonstrated different aspects of the system:
DuoRAM: Basic memory operations with private access
Binary Search: Searching in an array without revealing the search target
Heap: Priority queue operations with privacy guarantees
PRAC represents an important advancement in making secure multi-party computation practical for operations that require complex memory access patterns, which are essential for many real-world applications involving sensitive data
